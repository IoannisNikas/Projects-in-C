# Projects-in-C

2D_game_program : 
Ένα δισδιάστατο παιχνίδι επιβίωσης στο τερματικό, όπου ο παίκτης ψάχνει τον R2D2 αποφεύγοντας εχθρούς. Περιλαμβάνει δυναμική δημιουργία χάρτη και αλγόριθμο αυτόματης κίνησης (βάσει Ευκλείδειας απόστασης) για τους αντιπάλους.

Client_Server_program : 
Μια δικτυακή εφαρμογή (Client-Server) που επικοινωνεί μέσω TCP Sockets. Ο client στέλνει μαθηματικές παραστάσεις (π.χ. (5+3)*2) και ο server ελέγχει την ορθότητά τους και τις υπολογίζει κάνοντας χρήση δομών Στοίβας (Stack).

File_program : 
Ένα πρόγραμμα διαχείρισης δεδομένων (CLI) που λειτουργεί ως μίνι βάση δεδομένων. Κάνει χρήση Διπλά Συνδεδεμένης Λίστας (Doubly Linked List) στη μνήμη, επιτρέποντας την προσθήκη, διαγραφή, αναζήτηση εγγραφών, καθώς και την αποθήκευσή τους σε μόνιμο αρχείο .txt.
